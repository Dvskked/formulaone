Career

A full race weekend. Q1 and Q2 are simulated, then you go out for the Q3 pole attack lap. Grid locked, lights out, mandatory pit stops, fastest lap point, podium ceremony.

  • Real 25/18/15/12/10/8/6/4/2/1 points

FAQ

Questions from the paddock

Do I need to install anything?

No. APEX GP 2026 is a static site built with HTML5, CSS3 and modern JavaScript modules. Open it in any modern browser on desktop, tablet or phone.

Is this an official Formula 1 product?

No. APEX GP 2026 is an independent, non-commercial fan project. Team and driver names are used for identification only; all trademarks belong to their respective owners. No affiliation or endorsement.

How long is a race?

Each circuit is a stylised 2–3 km layout, so a flying lap runs 35–55 seconds. Races are configurable from a 4-lap Sprint to a 10-lap Grand Prix, with 1×–3× simulation speed for the impatient.

Can I save my career?

Yes. Careers are stored locally in your browser (localStorage). Autosaves happen after every round, and you can export or import a save file as JSON from the settings screen.

Is my progress shared anywhere?

No. The game runs entirely client-side — no accounts, no analytics, no network calls beyond loading the web font. Clearing browser data clears your saves.

Does it work on mobile?

Yes. The layout is responsive and the game detects touch input, showing a driving pad with steering and pedals. A gamepad also works on desktop and mobile browsers that expose the Gamepad API.
